# HE386 ROOT Assignment

Solutions for the HE386 Experimental High Energy Physics ROOT assignment.

## Requirements

- CERN ROOT
- C++ compiler
- `ntuple_array.root` provided with the assignment

The input file `ntuple_array.root` is not included in this repository. Place it in the repository root before running the analysis macros.

## Repository Structure

```text
Question1/    ROOT tutorial examples and reconstructed electron analysis
Question2/    Z-boson mass reconstruction
Question3/    MakeClass implementations
Question4/    Custom particle classes and analysis
